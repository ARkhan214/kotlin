1️⃣ API URLs এবং তাদের ব্যবহার

NewsAPI-তে তোমার যেগুলো ব্যবহার করতে চাও:

1. Sources দিয়ে top headlines

```text
https://newsapi.org/v2/top-headlines?sources=techcrunch&apiKey=YOUR_API_KEY
```

 এটা নির্দিষ্ট source এর news আনবে।
 Retrofit এ @Query দিয়ে parameter পাঠাতে হবে `sources`.

2. Country + Category দিয়ে top headlines

```text
https://newsapi.org/v2/top-headlines?country=us&category=business&apiKey=YOUR_API_KEY
```

 এটা নির্দিষ্ট country এবং category এর news আনবে।
 Retrofit এ parameter হবে `country` এবং `category`.

3. Everything endpoint

```text
https://newsapi.org/v2/everything?domains=wsj.com&apiKey=YOUR_API_KEY
```

 নির্দিষ্ট domain (site) থেকে সব news আনবে।
 Retrofit এ parameter হবে `domains`.

2️⃣ তোমার Retrofit interface (NewsApi.kt)

এখনের মতো তুমি লিখেছ:

```kotlin
interface NewsApi {

    @GET("v2/top-headlines")
    suspend fun getBreakingNews(
        @Query("country") countryCode: String="us",
        @Query("page") pageNumber: Int=1,
        @Query("apiKey") apiKey: String = API_KEY
    ): Response<NewsResponse>

    @GET("v2/everything")
    suspend fun searchForNews(
        @Query("q") query: String,
        @Query("page") pageNumber: Int=1,
        @Query("apiKey") apiKey: String = API_KEY
    ): Response<NewsResponse>

}
```

 getBreakingNews() → `top-headlines` জন্য।
 searchForNews() → `everything` জন্য।

3️⃣ Repository (NewsRepository.kt)

Repository হলো API + Database-এর মাঝখানে layer।
তুমি এখানে suspend functions বানাও যেগুলো Retrofit call করে।

```kotlin
class NewsRepository(val db: ArticleDatabase) {

    suspend fun getBreakingNews(countryCode: String, pageNumber: Int) =
        RetrofitInstance.api.getBreakingNews(countryCode, pageNumber)

    suspend fun getBreakingNewsBySource(source: String, pageNumber: Int) =
        RetrofitInstance.api.getBreakingNewsBySource(source, pageNumber)

    suspend fun getBreakingNewsByCategory(countryCode: String, category: String, pageNumber: Int) =
        RetrofitInstance.api.getBreakingNewsByCategory(countryCode, category, pageNumber)

    suspend fun searchForNewsByDomain(domain: String, pageNumber: Int) =
        RetrofitInstance.api.searchForNews(domain = domain, pageNumber = pageNumber)

}
```

 Repository শুধু API call করে এবং Response return করে।
 কোনো UI logic Repository-তে থাকে না।

4️⃣ ViewModel (NewsViewModel.kt)

ViewModel হলো UI logic + LiveData holder।
এখানে API কল হয় Repository এর মাধ্যমে এবং UI কে LiveData দিয়ে update করা হয়।

```kotlin
class NewsViewModel(val newsRepository: NewsRepository) : ViewModel() {

    val breakingNews: MutableLiveData<Resource<NewsResponse>> = MutableLiveData()
    var breakingNewsPage = 1

    init {
        getBreakingNews("us")
    }

    fun getBreakingNews(countryCode: String) = viewModelScope.launch {
        breakingNews.postValue(Resource.Loading())
        val response = newsRepository.getBreakingNews(countryCode, breakingNewsPage)
        breakingNews.postValue(handleBreakingNewsResponse(response))
    }

    private fun handleBreakingNewsResponse(response: Response<NewsResponse>): Resource<NewsResponse> {
        if (response.isSuccessful) {
            response.body()?.let { resultResponse ->
                return Resource.Success(resultResponse)
            }
        }
        return Resource.Error(response.message())
    }

}
```

 Resource class হলো status holder (Loading / Success / Error).
 UI শুধু এই `breakingNews` LiveData observe করে, আর data দেখায়।

5️⃣ Fragment (BreakingNewsFragment.kt)

Fragment হলো UI layer, এখানে RecyclerView আছে।

Workflow:

1. Fragment তে ViewModel inject হয়:

```kotlin
private val viewModel: NewsViewModel by activityViewModels {
    NewsViewModelProviderFactory(NewsRepository(ArticleDatabase(requireContext())))
}
```

2. RecyclerView setup:

```kotlin
private fun setupRecyclerView() {
    newsAdapter = NewsAdapter()
    binding.rvBreakingNews.apply {
        adapter = newsAdapter
        layoutManager = LinearLayoutManager(requireContext())
    }
}
```

3. LiveData observe:

```kotlin
viewModel.breakingNews.observe(viewLifecycleOwner) { resource ->
    when(resource) {
        is Resource.Success -> {
            hideProgressBar()
            resource.data?.let {
                newsAdapter.differ.submitList(it.articles)
            }
        }
        is Resource.Error -> {
            hideProgressBar()
            Toast.makeText(requireContext(), resource.message, Toast.LENGTH_SHORT).show()
        }
        is Resource.Loading -> {
            showProgressBar()
        }
    }
}
```

 Data আসলে RecyclerView Adapter কে দেওয়া হয়।
 Adapter তার differ.submitList() দিয়ে RecyclerView update করে।

7️⃣ Full Workflow Summary

1. Fragment observe করে LiveData.
2. Fragment call করে ViewModel method: `viewModel.getBreakingNews("us")`
3. ViewModel call করে Repository: `newsRepository.getBreakingNews("us")`
4. Repository call করে Retrofit: `RetrofitInstance.api.getBreakingNews("us")`
5. Retrofit network call করে API থেকে JSON response আনে।
6. Response ViewModel এ `Resource.Success` হিসেবে LiveData-তে পোস্ট করা হয়।
7. Fragment observe করে response data এবং RecyclerView update করে।
8. User sees news in RecyclerView.
 Key Points:

 Fragment: UI, observe LiveData
 ViewModel: Holds LiveData, calls repository
 Repository: API call
 RetrofitInstance: actual network request
 Adapter: RecyclerView update
