Question: 	Kotlin a koto type er function ache?
---------

Answer:		Kotlin-এ মূলত Named, Local, Member, Extension, Lambda, Higher-order, Inline, Single-expression ও Default parameter সহ বিভিন্ন ধরনের function আছে।
-------

## 🔹 1️⃣ Normal / Named Function
সবচেয়ে basic function।

fun add(a: Int, b: Int): Int {
    return a + b
}


## 🔹 2️⃣ Function with Default Parameter
Parameter না দিলেও চলে।

fun greet(name: String = "Rahim") {
    println("Hello $name")
}

---

## 🔹 3️⃣ Single-Expression Function
এক লাইনের function।

fun square(x: Int) = x * x

---

## 🔹 4️⃣ Local Function
একটা function-এর ভিতরে আরেকটা function।

fun outer() {
    fun inner() {
        println("Inside inner")
    }
    inner()
}

---

## 🔹 5️⃣ Member Function
Class-এর ভিতরের function।

class Person {
    fun speak() {
        println("I am speaking")
    }
}

---

## 🔹 6️⃣ Extension Function  (Kotlin-এর power)
বিদ্যমান class-এ নতুন function যোগ করা।

fun String.reverseText(): String {
    return this.reversed()
}

ব্যবহার:
"Rahim".reverseText()

---

## 🔹 7️⃣ Lambda Function (Anonymous Function)
নাম ছাড়া function।

val sum = { a: Int, b: Int -> a + b }
---

## 🔹 8️⃣ Higher-Order Function
যে function অন্য function কে parameter নেয় বা return করে।

fun operate(a: Int, b: Int, action: (Int, Int) -> Int): Int {
    return action(a, b)
}
---

## 🔹 9️⃣ Inline Function
Performance optimize করার জন্য।

inline fun runFast(action: () -> Unit) {
    action()
}

---

## 🔹 Bonus (কম ব্যবহৃত কিন্তু গুরুত্বপূর্ণ)
### 🔸 Tail Recursive Function
Recursion optimize করে।

tailrec fun factorial(n: Int, result: Int = 1): Int {
    return if (n == 1) result else factorial(n - 1, n * result)
}

---

##  এক নজরে Summary
| Type | নাম                         |
| ---- | --------------------------- |
| 1    | Normal Function             |
| 2    | Default Parameter Function  |
| 3    | Single Expression Function  |
| 4    | Local Function              |
| 5    | Member Function             |
| 6    | Extension Function          |
| 7    | Lambda / Anonymous Function |
| 8    | Higher-Order Function       |
| 9    | Inline / Tailrec Function   |

#  Kotlin-এ `fun` লেখার ফুল গাইড 
---

##  1️⃣ Kotlin function-এর মূল গঠন (Structure)

```kotlin
fun functionName(parameter: Type): ReturnType {
    // code
    return value
}
```

এখন এটা ভেঙে ভেঙে বুঝি

---

## 2️⃣ প্রতিটা জিনিস কেন লাগে?

### 🔹 `fun`

 Kotlin-কে বলছি:

> “আমি এখন একটা function বানাচ্ছি”

 এটা mandatory (না দিলে function হবে না)

---

### 🔹 `functionName`

 function-এর নাম
 নিজের ইচ্ছামতো দিতে পারো (verb হলে ভালো)

```kotlin
fun add
fun loginUser
fun calculateTotal
```

 Rule:

* ছোট হাতের অক্ষর দিয়ে শুরু
* space নেই
* meaningful নাম

---

### 🔹 `( )` → parameter list

 এখানে input ডাটা আসে

```kotlin
fun add(a: Int, b: Int)
```

 যদি input না লাগে:

```kotlin
fun sayHello()
```

---

### 🔹 `parameter: Type`

 Kotlin-এ **type লেখা বাধ্যতামূলক**

```kotlin
a: Int
name: String
price: Double
```

❌ ভুল:

```kotlin
fun add(a, b) // error
```

---

### 🔹 `: ReturnType`

 function শেষে কী টাইপের ডাটা ফেরত দিবে

```kotlin
fun add(a: Int, b: Int): Int
```

 যদি কিছু return না করে:

```kotlin
fun showMessage(): Unit
```

 `Unit` না লিখলেও চলে:

```kotlin
fun showMessage() {
    println("Hi")
}
```

---

### 🔹 `{ }` → function body

 আসল কাজ এখানেই হয়

```kotlin
{
   // logic
}
```

---

### 🔹 `return`

 function থেকে value পাঠানো

```kotlin
return a + b
```

ReturnType দিলে → return দিতে হবে

---

##  4️⃣ কখন কী দিলে কী দিতে হবে? (Rule Table)

| যদি এটা করো     | তাহলে এটা দিতে হবে        |
| --------------- | ------------------------- |
| parameter নাও   | `(param: Type)`           |
| return করতে চাও | `: ReturnType` + `return` |
| return না করো   | `Unit` বা কিছুই না        |
| এক লাইনের logic | `{}` বাদ দিয়ে `=`         |

---

##  5️⃣ Shortcut (Single line fun)

```kotlin

```

 এখানে:

* `{ }` নেই
* `return` নেই
* `=` আছে

##  6️⃣ Common ভুল (Beginner দের)

❌ Type না দেওয়া
❌ ReturnType দিয়ে `return` না লেখা

```kotlin

```

##  7️⃣ Real Android Example

```kotlin
}
```

**Kotlin-এ `fun` লেখার structure আসলে কয়েকভাবে লেখা যায়**। একদম বেসিক থেকে ধরলে **৭টা সবচেয়ে গুরুত্বপূর্ণ `fun` structure** আছে।

# 🔹 Kotlin-এ `fun` এর Structure কয়টা?

👉 **মোট ৭ ধরনের `fun structure` বেশি ব্যবহার হয়**

---

## 1️⃣ Normal Block Function (সবচেয়ে basic)

```kotlin
fun add(a: Int, b: Int): Int {
    return a + b
}
```

📌 ব্যবহার করো যখন:

* একাধিক লাইন logic
* condition / loop আছে

---

## 2️⃣ Function without Return (Unit)

```kotlin
fun showMessage(message: String) {
    println(message)
}
```

📌 এখানে:

* `: Unit` লেখা নাই
* `return` নাই

---

## 3️⃣ Single-Expression Function (`=` structure)

```kotlin
fun square(x: Int): Int = x * x
```

📌 ব্যবহার করো যখন:

* এক লাইনের হিসাব
* simple logic

---

## 4️⃣ Function with Default Parameter

```kotlin
fun greet(name: String = "Rahim") {
    println("Hello $name")
}
```

📌 কল করার সময়:

```kotlin
greet()
greet("Karim")
```

---

## 5️⃣ Local Function (fun এর ভিতরে fun)

```kotlin
fun outerFun() {
    fun innerFun() {
        println("Inside inner")
    }
    innerFun()
}
```

📌 ব্যবহার:

* logic ভাগ করার জন্য
* বাইরে দরকার নেই এমন function

---

## 6️⃣ Extension Function Structure ⭐

```kotlin
fun String.myLength(): Int {
    return this.length
}
```

📌 কল:

```kotlin
"Bangladesh".myLength()
```

---

## 7️⃣ Lambda / Anonymous Function Structure

```kotlin
val sum = { a: Int, b: Int -> a + b }
```

অথবা

```kotlin
val sum: (Int, Int) -> Int = { a, b ->
    a + b
}
```

📌 ব্যবহার:

* click listener
* higher-order function

Question: Java and Kotlin er vetor function er mil omil dekhao
---------

Answer:
-------
অবশ্যই আঃ রহিম খান 😄
আমি তোমাকে সহজভাবে **Java এবং Kotlin-এ function / method-এর মিল ও ভিন্নতা** দেখাচ্ছি, step by step, table সহ।

---

# 🔹 1️⃣ Basic Function / Method Structure

### **Java**

```java
int add(int a, int b) {
    return a + b;
}
```

### **Kotlin**

```kotlin
fun add(a: Int, b: Int): Int {
    return a + b
}
```

**Observation / মিল:**

* দুটোতেই **parameter + return type + body** আছে
* দুইটোর কাজ একদম একই

**ফারাক:**

* Kotlin-এ `fun` keyword ব্যবহার হয়
* Kotlin-এ semicolon optional

---

# 🔹 2️⃣ Function Without Return

### **Java**

```java
void showMessage(String msg) {
    System.out.println(msg);
}
```

### **Kotlin**

```kotlin
fun showMessage(msg: String) {
    println(msg)
}
```

**Observation / মিল:**

* Return না হলে Java-তে `void`, Kotlin-এ `Unit` (লিখলেও চলে না-ও লেখা যায়)

---

# 🔹 3️⃣ Single-line Function / Expression

### **Java**

```java
int square(int x) {
    return x * x;
}
```

### **Kotlin**

```kotlin
fun square(x: Int) = x * x
```

**Observation:**

* Kotlin-এ `=` দিয়ে single-expression function লেখা যায়
* Java-তে সব সময় `{}` এবং `return` লাগবে

---

# 🔹 4️⃣ Default Parameter

### **Java**

```java
void greet(String name) {
    if(name == null) name = "Rahim";
    System.out.println("Hello " + name);
}
```

### **Kotlin**

```kotlin
fun greet(name: String = "Rahim") {
    println("Hello $name")
}
```

**Observation:**

* Kotlin-এ default parameter সরাসরি signature-এ দেওয়া যায়
* Java-তে condition/overloading দিয়ে করতে হয়

---

# 🔹 5️⃣ Overloading / Lambda / Anonymous Function

### **Java (Anonymous / Lambda)**

```java
Runnable r = new Runnable() {
    public void run() {
        System.out.println("Running");
    }
};
```

```java
Runnable r = () -> System.out.println("Running");
```

### **Kotlin**

```kotlin
val r = Runnable { println("Running") }
```

**Observation:**

* Kotlin-এ concise
* Anonymous function বা lambda syntax অনেক ছোট
* Java 8+ ছাড়া lambda নেই

---

# 🔹 6️⃣ Extension Function (Kotlin Unique)

### **Java:** Not Available

* Java-তে extension function নেই
* করতে হলে utility class-এ static method বানাতে হয়

### **Kotlin**

```kotlin
fun String.addExclamation() = this + "!"
```

📌 call:

```kotlin
println("Hello".addExclamation()) // Hello!
```

---

# 🔹 Summary Table

| Feature / Type     | Java                     | Kotlin                              | Mil / Difference                |
| ------------------ | ------------------------ | ----------------------------------- | ------------------------------- |
| Basic function     | `int add(int a, int b)`  | `fun add(a: Int, b: Int): Int`      | একই কাজ, Kotlin-এ `fun` keyword |
| No return          | `void showMessage()`     | `fun showMessage()`                 | Kotlin-এ `Unit` optional        |
| Single line        | `{ return x*x; }`        | `= x*x`                             | Kotlin concise                  |
| Default param      | null check / overloading | `fun greet(name: String = "Rahim")` | Kotlin direct support           |
| Lambda             | Java 8+ only             | `val r = { ... }`                   | Kotlin concise, everywhere      |
| Extension function | Not available            | `fun String.extFunc()`              | Kotlin exclusive                |

---

💡 **Observation:**
Kotlin অনেকটা Java-এর upgraded version।

* Mil: Syntax structure একই, OOP & parameter handling similar
* Omil / Difference: `fun` keyword, default parameters, single-expression, extension functions, concise lambda
